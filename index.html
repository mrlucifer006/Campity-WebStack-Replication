CHAPTERS 3, 5, 6 & 7 ARCHITECTURE

🏛️ Dual-Stack Architecture & Benchmarking

Full-Stack Web Architecture Replication: Interoperable PHP and Java Servlets implementations.

Figure 3.1: TaskFlow Dual-Stack System Architecture Diagram

High-Performance 3-Tier Design

The platform decouples Presentation, Application, and Data tiers to allow independent execution across both PHP and Java EE servlet engines while sharing a single SQLite database (campity.db):

1. Shared Presentation Tier
Semantic HTML5, CSS3 CSS Variables design system, theme switcher (4 styles), dynamic escrow stake calculation.
2. PHP Application Tier (Port 8000)
SQLite PDO persistence, bcrypt password hashing, session state, REST API endpoint (/api/quests/prioritized).
3. Java Servlets Tier (Port 8080)
Embedded JDK HttpServer (zero Tomcat dependency), pure JDBC Data Access Objects (DAO), in-memory binary Max-Heap.

Figure 3.2: TaskFlow Relational Entity-Relationship Diagram

ACID Relational Model & Escrow State Machine

Financial integrity is guaranteed through two-sided escrow locks and transaction ledger logging:

Figure 5.1: Task Lifecycle State Machine Transition Diagram

  • Escrow Guarantee: Bounty credits locked immediately upon task creation.
  • 10% Collateral Stake: Student helpers lock 10% stake to eliminate task hoarding.
  • Auditable Ledger: All balance modifications recorded in transactions table.

☕ Java Servlets & Standalone JDK EmbeddedServer

The Java implementation runs standalone via JDK HttpServer or standard Java EE Tomcat WAR.

// Run standalone without Tomcat:
java -cp "java-servlets/bin:lib/*" com.campity.server.EmbeddedServer

// Java In-Memory Max-Heap Priority Queue Comparator:
PriorityQueue<Quest> pq = new PriorityQueue<>((a, b) -> {
    int scoreA = calculatePriorityScore(a);
    int scoreB = calculatePriorityScore(b);
    return Integer.compare(scoreB, scoreA); // Max-Heap descending
});

🐘 PHP 8.x Architecture & SQLite PDO

Run anywhere with PHP's built-in web server. Automatic SQLite schema migrations on first run.

// Start PHP Stack:
cd php && php -S localhost:8000

// PriorityQueue Engine (php/includes/PriorityQueue.php):
$queue = new PriorityQueue();
foreach ($openTasks as $task) {
    $queue->insert($task, $task['priority_score']);
}
$prioritizedTasks = $queue->extractAll();

Figure 7.1: Latency & Throughput Benchmark (PHP vs Java Servlets)

Performance Benchmark Summary

Tested under 50 concurrent client connections using SQLite WAL mode:

  • Java Servlets: 9.2 ms average latency, 380 requests/sec peak throughput. In-memory heap ensures sub-millisecond sorting.
  • PHP SQLite: 18.4 ms average latency, 145 requests/sec peak throughput. Exceptional lightweight resource footprint.
  • Zero Deadlocks: Atomic transaction isolation guarantees 100% financial consistency.

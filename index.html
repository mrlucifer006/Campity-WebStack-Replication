High-Performance 3-Tier Design

The platform cleanly decouples presentation, business logic, and persistence. Both engines share the same SQLite database (campity.db) with atomic transactions:

1. Shared Presentation Tier
HTML5, CSS3 Custom Properties (4 themes), dynamic stake calculator, and toast messaging.
2. PHP Application Tier (Port 8000)
SQLite PDO persistence, bcrypt hashing, session state, REST API (/api/quests/prioritized).
3. Java Servlets Tier (Port 8080)
Standalone JDK HttpServer (zero external container requirement), pure JDBC DAO, in-memory Max-Heap.

// Run standalone without Tomcat:
java -cp "java-servlets/bin:lib/*" com.campity.server.EmbeddedServer

// Java EE 4.0 In-Memory Max-Heap Priority Queue Comparator:
PriorityQueue<Quest> priorityQueue = new PriorityQueue<>((a, b) -> {
    int scoreA = calculatePriorityScore(a);
    int scoreB = calculatePriorityScore(b);
    return Integer.compare(scoreB, scoreA); // Max-Heap: Highest urgency at root
});

public static int calculatePriorityScore(Quest quest) {
    int weight = CATEGORY_WEIGHTS.getOrDefault(quest.getCategory(), 40);
    double bountyFactor = quest.getReward() * 0.5;
    int urgencyBonus = calculateUrgencyBonus(quest.getDeadline());
    return (int)((weight * 10) + bountyFactor + urgencyBonus);
}

// PHP Priority Comparator (php/includes/PriorityQueue.php):
usort($openTasks, function($a, $b) {
    $scoreA = ($a['category_weight'] * 10) + ($a['reward'] * 0.5) + $a['urgency_bonus'];
    $scoreB = ($b['category_weight'] * 10) + ($b['reward'] * 0.5) + $b['urgency_bonus'];
    return $scoreB <=> $scoreA; // Spaceship operator for descending sort
});
